# Лабораторная работа 11

Требования к решению

Фреймворк Flask или FastAPI или любой другой Python-фреймворк (микрофреймворк — без разветвлённой структуры файлов и папок внутри)
Формат ответа по маршруту /login: {"author": "__ваш логин__"}
Реализация дополнительных решений с использованием более чем одного фреймворка (варианты: Node.js, Django, Go)
Реализация фронтэнда и отправка данных на сервер с использованием какого-либо фронтэнд-фреймворка или библиотеки (Vue.js, Svelte, React)
Вывод и отображение исходного текста на странице с формой (без перезагрузки страницы, асинхронно)
